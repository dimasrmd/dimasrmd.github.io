## Capaian Minggu Ini
Tuliskan pencapaian utama: 
1. Mastery of Advanced OOP: Berhasil memahami dan membedakan konsep relasi Asosiasi, Agregasi, Komposisi, serta implementasi Polymorphism di Java.
2. AI Algorithm Implementation: Menguasai konsep algoritma Best-First Search dan varian optimasi Simulated Annealing Hill Climbing.
3. Server Network Configuration: Berhasil merancang dan mengonfigurasi topologi jaringan yang melibatkan layanan server pada simulasi Cisco Packet Tracer.
4. UI Design Progress: Secara konsisten melanjutkan pengembangan antarmuka (UI) web untuk tugas besar kelompok IMK.

## Progress Terhadap Target Semester
- Target Semester: Membangun portofolio digital yang komprehensif menggunakan Astro dan menguasai analisis efisiensi algoritma serta konsep Advanced OOP (Java).
- Progress saat ini: 35%
- Keterangan: Mengalami peningkatan sebesar 5%. Target penguasaan Advanced OOP kini memasuki fase krusial karena materi telah mencapai puncaknya di bab Polymorphism dan interaksi antar-objek.

## Kendala Mingguan
- Akademik: Mencerna perbedaan mendasar antara Agregasi dan Komposisi dalam kode Java membutuhkan abstraksi logika yang sangat teliti. Materi Congestion Control di Jarkom juga memiliki teori yang cukup padat.
- Teknis: Menambahkan perangkat Server di Cisco Packet Tracer memerlukan konfigurasi services (layanan) tambahan yang membuat troubleshooting jaringan menjadi lebih kompleks dari biasanya.
- Pribadi: Beban pengerjaan tiga laporan praktikum dan tugas UI web membuat waktu review materi teori (seperti Strategi Algoritma) menjadi sedikit berkurang.

## Evaluasi Diri
- Keberhasilan Terbaik: Mampu menangkap konsep Polymorphism dengan baik dan mengumpulkan seluruh laporan praktikum tepat waktu meski jadwal sangat padat.
- Kesalahan Terbesar: Terlalu fokus pada penyelesaian Laprak sehingga kurang memberikan waktu luang untuk mengulang materi Strategi Algoritma di hari Rabu.
- Strategi Minggu Depan: Menggunakan sistem cicil—mengerjakan kerangka dasar laporan praktikum di hari yang sama dengan jadwal praktikum agar beban tidak menumpuk di malam hari.
