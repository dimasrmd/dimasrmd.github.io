Minggu kedua belas ini adalah fase di mana teori-teori rumit mulai bertransformasi menjadi produk nyata. Fokus utama minggu ini sangat didominasi oleh pengerjaan berbagai Tugas Besar (Tubes), mulai dari mencari *dataset* dan merancang fungsi defuzifikasi untuk DKA, hingga tahap integrasi program pada Tubes Jarkom. Secara teknis, pemahaman saya tentang ekosistem Java diuji lebih jauh dengan masuknya materi *Java Server Pages* (JSP) menggunakan Tomcat hingga konsep arsitektur REST API. Di tengah kesibukan koding dan *debugging*, saya juga menyempatkan diri untuk menyelesaikan *short course* komunikasi demi menjaga keseimbangan antara *hard-skill* dan *soft-skill*.

## Capaian Minggu Ini
1. **Fuzzy Logic Implementation**: Berhasil mengimplementasikan *library scikit-fuzzy* di Python dan merancang fungsi defuzifikasi mandiri untuk kebutuhan Tugas Besar DKA.
2. **Enterprise Java Fundamentals**: Berhasil melakukan konfigurasi *server* Apache Tomcat untuk menjalankan JSP dan mulai memahami konsep dasar REST API pada Java.
3. **Project Integration**: Memasuki fase krusial pada Tubes Jarkom yaitu integrasi program, serta sukses mempresentasikan *Mini Project* di mata kuliah WGTIK.
4. **Soft-Skill Development**: Membuktikan komitmen pada pengembangan diri dengan menyelesaikan kursus komunikasi, sebuah kemampuan esensial untuk kolaborasi tim dalam *Software Engineering*.

## Progress Terhadap Target Semester
- **Target Semester**: Membangun portofolio digital yang komprehensif menggunakan Astro dan menguasai analisis efisiensi algoritma serta konsep Advanced OOP (Java).
- **Progress saat ini**: **60%**
- **Keterangan**: Ada peningkatan 5%. Target penguasaan *Advanced OOP* kini mencapai puncaknya. Mempelajari ekosistem *Web/Backend* Java melalui JSP dan REST API adalah lompatan besar dari sekadar *coding* Java dasar menuju standar industri nyata.

## Kendala Mingguan
- **Akademik**: Memahami *Propositional Logic* di DKA dan *Parity Check* di *Link Layer* Jarkom membutuhkan dasar matematika diskrit dan logika bitwise yang cukup kuat.
- **Teknis**: Melakukan integrasi program dari berbagai anggota tim pada Tubes Jarkom sering kali memicu *error* atau *conflict* pada kode. Selain itu, konfigurasi awal Tomcat untuk JSP terkadang mengalami masalah *port clashing*.

## Evaluasi Diri
- **Keberhasilan Terbaik**: Mampu menjaga emosi dan ketenangan dalam berkolaborasi untuk Tugas Besar, yang sangat terbantu oleh materi *Communication Skill* yang baru saja diselesaikan.
- **Kesalahan Terbesar**: Menumpuk pengerjaan dua Laporan Praktikum DKA (Modul 12 dan 13) di hari Kamis, yang seharusnya bisa diselesaikan langsung setelah praktikum di hari Senin.
- **Strategi Minggu Depan**: Membuat *to-do list* harian yang lebih spesifik untuk setiap Tugas Besar, agar progresnya terukur dan tidak ada *task* anggota kelompok yang *bottleneck* (tertahan).

## Rencana Minggu Depan
1. **Target 1**: Memfinalisasi model logika *Fuzzy* untuk Tugas Besar DKA agar siap diuji coba dengan *dataset* utuh.
2. **Target 2**: Menyelesaikan fase integrasi program Tubes Jarkom dan melakukan eksplorasi mendalam terkait pembuatan *endpoint* REST API di Java (PBO).
